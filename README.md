# FlowPost - Social Media Management & Automation

FlowPost is a comprehensive platform for managing social media accounts, scheduling posts, and automating marketing workflows.

## Features

- **Multi-Account Management**: Connect and manage multiple Facebook and Instagram accounts.
- **Content Scheduling**: Schedule posts for future publication with a visual calendar.
- **Media Library**: Manage and organize your marketing assets.
- **Analytics Dashboard**: Track engagement and performance across all connected accounts.
- **Marketing Automation**: Automated workflows for campaign execution.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Framer Motion
- **Backend/Auth**: Supabase
- **API**: Meta Graph API
- **Automation**: Python-based marketing automation system

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Set up environment variables in a `.env` file.
4. Run the development server: `npm run dev`

## Marketing System

The `marketing_system/` directory contains tools for automated social media publishing using Python scripts and CSV-based scheduling.
